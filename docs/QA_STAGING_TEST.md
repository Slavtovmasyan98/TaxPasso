# QA-тест Taxpasso на staging: экраны и логика

Задание для агента с браузером (GPT / ChatGPT Agent). Проверяет 10 критериев приёмки миграций 011–015
на **staging**. Рабочий сайт (`taxpasso.vercel.app`, `taxpassopartners.vercel.app`) **не трогать**.

## Правила для агента

1. Работать только на staging-адресах ниже. Если адрес без `git-staging` — остановиться.
2. Не вводить реальные паспорта и данные: только тестовые PDF и вымышленные имена.
3. Каждый шаг: выполнить → сравнить с «Ожидается» → записать **PASS** / **FAIL**. При FAIL — скриншот и точный текст на экране.
4. Двойной клик проверять там, где указано: два быстрых нажатия подряд.
5. Не менять настройки Supabase и Vercel, не открывать SQL.
6. Для каждой роли — отдельное окно инкогнито (или отдельный профиль браузера).
