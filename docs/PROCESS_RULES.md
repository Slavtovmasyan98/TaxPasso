# Правила процесса Taxpasso

Этот файл — источник правды о бизнес-правилах. Любое изменение кода или базы должно им соответствовать.
Если правило меняется — сначала меняется этот файл (в том же pull request).

## Главный принцип: админ всегда первый

Админ выбирает и назначает партнёра. **Ничего из того, что делает партнёр, не доходит до клиента и не меняет
заказ без подтверждения админа.** Партнёр только предлагает — админ подтверждает, возвращает или решает сам.

| Действие | Партнёр | Админ | Клиент видит |
|---|---|---|---|
| Видеть заказ | только назначенный админом | все | свои |
| Этап заказа | предлагает (свой прогресс) | подтверждает по одному | после подтверждения |
| Основание ITIN | предлагает одобрить / отклонить с причиной | подтверждает / возвращает / решает сам | после подтверждения |
| Проверка документа клиента | предлагает принять / отклонить с причиной | подтверждает / возвращает / решает сам | после подтверждения |
| Данные компании, EIN | вносит | одобряет | после одобрения |
| Номер ITIN | вносит | одобряет | после одобрения |
| Документы партнёра | загружает → «Отправить» | «Клиенту» или «Вернуть» | после «Клиенту» |
| Анкета клиента (владельцы, компания) | **не может менять** | может | — |
| Оплата, отмена, возврат, срок пакета | **не видит и не может** | делает | видит |
| Запрос / отказ IRS | — | фиксирует | видит |

## Консультация специалиста по основанию ITIN

- Если опросник не выявил основание или клиент выбрал «Не знаю», создаётся отдельный заказ `itin_consult`.
- До передачи заказа клиент указывает Telegram или WhatsApp и предпочтительное время связи.
- На `itin_consult` назначается только партнёр с квалификацией **SPECIALIST**; CAA/CPA на консультацию не назначается.
- Специалист проводит интервью и только **предлагает** план: одобрить основание с продуктом
  `itin_standard` / `itin_return` либо отказать с обязательной причиной.
- Клиент не видит предложение, рекомендуемый продукт и внутреннее решение специалиста до подтверждения администратором.
- Администратор подтверждает предложение как есть либо отклоняет заказ самостоятельно с причиной.
- До подтверждения администратором оплата консультационного/ITIN-заказа запрещена.
- При одобрении продукт меняется на выбранный ITIN-продукт, основание становится `approved`, этап — «Документы».
- После одобрения специалист временно сохраняет доступ для непрерывности процесса, но не получает денежных данных.
  После назначения CAA или CAA/CPA специалист теряет доступ к заказу.
- Для `itin_return` назначается только **CAA/CPA**; для `itin_standard` — **CAA** или **CAA/CPA**.
- При отказе заказ закрывается, а клиент видит подтверждённую администратором причину.
- Контактные данные консультации можно менять только владельцу открытого заказа и только во время консультационного потока.

## Партнёр и деньги

Партнёр **ничего не видит о деньгах**: ни статуса оплаты, ни сумм, ни возвратов, ни заметок об оплате.
Заказы он получает через `partner_orders()` без денежных полей; вместо оплаты — только «в работе: да/нет».
Расчёты с партнёрами — вне системы.

## Оплата

| Продукт | Когда платит клиент | Возврат |
|---|---|---|
| LLC Wyoming / Delaware | 100% сразу | нет (проект; текст политики — после юриста) |
| Пакет LLC + ITIN (WY / DE) | 100% сразу | при отказе в основании ITIN — **$100** |
| ITIN Standard / ITIN + подготовка декларации | 100% **после одобрения основания** | при отказе IRS — **следующая подача бесплатно** |

Работа партнёра начинается только после оплаты.

## Этапы

- **LLC:** Анкета → Проверка → Подано в штат → Зарегистрирована → EIN запрошен → EIN получен → Закрыт → Operations.
  Финал: EIN одобрен + Articles, письмо EIN, Operating Agreement опубликованы.
- **ITIN Standard:** Документы → Интервью CAA → Отправлено в IRS → ITIN получен → Закрыт.
- **ITIN + подготовка декларации:** Документы → Подготовка декларации → Подписано клиентом → Интервью CAA →
  Отправлено в IRS → ITIN получен → Закрыт.
- **Пакет:** поток LLC + поток ITIN Standard. Отказ по ITIN останавливает только ITIN.
- Финал ITIN: номер ITIN одобрен + письмо IRS (CP565) опубликовано.
- Отказ IRS: поток ITIN возвращается к «Документы», попытка +1, повторная подача бесплатно.

## Отмена

Только админ, с причиной, пока нет факта подачи (штат / IRS) ни у клиента, ни у партнёра.
Отмена деньги не возвращает — возврат фиксируется отдельно.

## Назначение партнёра

- ITIN + подготовка декларации — только **CAA/CPA**.
- ITIN Standard и пакеты — **CAA** или **CAA/CPA**.
- LLC — любой партнёр.
- Смена партнёра сбрасывает его неподтверждённые предложения; факт подачи сохраняется.

## Выпуск

- `staging` в `main` **не сливается никогда**.
- Путь: `feature/*` → автопроверка → `staging` + workflow `staging-db` → сквозной тест → PR в `main`
  **одновременно** с применением миграций к рабочей базе.
- Миграции — только файлами в репозитории. Никаких изменений в рабочей базе в обход репозитория.
