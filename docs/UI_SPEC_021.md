# Интерфейс под миграцию 021 (срок обслуживания и госсбор)

Тексты — `docs/CHECKOUT_COPY.md`. Правила — ниже. Макет шага оплаты согласован (интерактивный макет из чата).

## Клиентский чекаут (LLC и пакеты)
1. Переключатель срока «1 год (включён) · 2 года · 3 года» → `set_order_service_years(p_order, p_years)` при каждом выборе.
   Для ITIN-продуктов блок не показывать.
2. После каждого изменения (срок, услуги) запрашивать `order_payment_due(p_order)` и рисовать сводку из ответа:
   `base_cents` → строка пакета; `renewals_cents` → «Обслуживание»; `state_fee_cents` → «Государственный сбор штата»
   (метка «оплачивается штату»); `addons_cents` → выбранные услуги; `total_cents` → «Итого».
   Считать суммы в интерфейсе самостоятельно **нельзя**: только показывать ответ сервера.
3. Строка «В том числе государственные сборы: {state_fee_cents} · услуги Taxpasso: {total_cents − state_fee_cents}».
4. Блок «Профиль компании» (число участников, цели) — только для рекомендаций, на сервер не отправляется.
   Число участников берётся из анкеты, если она уже собрана; иначе спросить.
   - один участник → у Form 5472 метка «Рекомендуем» и причина `f5472.reason`;
   - два и более → `f5472.unavailable`, чекбокс недоступен;
   - цель «банк / платёжная система / маркетплейс» → у почтового адреса метка «Рекомендуем» и `addr.reason`.
5. **Ничего платного не отмечать заранее.** Рекомендуемое выделяется рамкой и меткой, галочку ставит клиент.
6. Форма 5472 и почтовый адрес (`request_addon`) доступны только когда услуги включены в базе (`available_addons`).
   Цена за N лет = цена в год × N; годы услуги совпадают со сроком обслуживания.

## Админ (Partners)
- Кнопка «Отметить оплату»: вызывать `mark_order_paid_manually(p_order, p_note, p_amount_cents = total_cents)`.
  Под полем суммы показать состав: пакет / обслуживание / госсбор / услуги.
- Форма без суммы допустима только при сроке в 1 год и без ожидающих услуг; иначе сервер ответит «Amount required».
- В карточке оплаченного заказа — таблица строк `order_payment_lines` (тип `state_fee` подписать «транзит: оплатить штату»).
  Это напоминание: госсбор нужно оплатить штату от имени клиента в срок (WY — месяц регистрации; DE — 1 июня).
- Экран цен: `product_prices`, `renewal_prices` (`set_renewal_price(state, renewal_cents, state_fee_cents)`).

## Страница /pricing
- Заменить три строки услуг и добавить пояснение калькулятора по `docs/CHECKOUT_COPY.md`, раздел «Страница /pricing».
- Из калькулятора убрать «Почтовый адрес» и «Ускоренная регистрация» до подтверждения цен.
- Кнопка «Посчитать» переносит выбранный срок в мастер: `/app/start?years=2` (предвыбор, ничего не покупает).

## Правила и оговорки
- Госсбор — транзит: не выручка Taxpasso. В отчётах о марже суммируются `service_year` и `package`, но не `state_fee`.
- Ставка Wyoming «от $60»: если штат возьмёт больше, порядок доплаты определяет владелец (пока не задан).
- Клиент выбирает срок только до оплаты. Продление после оплаты и напоминания о сроках — отдельная работа.
