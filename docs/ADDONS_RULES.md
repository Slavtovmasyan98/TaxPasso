# Доп. услуги (add-ons): правила

Добавить в `docs/PROCESS_RULES.md` (раздел «Оплата») или хранить рядом.

- Add-ons — простые услуги с фиксированной ценой: **Business Address**, **Form 5472 + pro-forma 1120**, **DE Expedited Filing**.
  Продаются только к LLC и пакетам (`llc_wy`, `llc_de`, `bundle_wy`, `bundle_de`); DE Expedited — только к DE.
  **ITIN (`itin_standard`, `itin_return`) в add-ons не участвует** — у него свой workflow.
- **Запрос ≠ выдача.** Клиент запрашивает услугу (`request_addon`) → статус `pending_payment`. Услуга становится
  `active` только после оплаты: оплата заказа активирует запрошенные при оформлении услуги (клиент платит одной суммой),
  докупка после оплаты — отдельное подтверждение админа (`mark_addon_paid`; позже — вебхук Stripe).
- **Цена — с сервера.** Клиент передаёт только код услуги. В `order_addons` хранится снимок цены на момент запроса.
- **Цена подтверждена?** Услугу нельзя включить в продажу (`active`), пока админ не подтвердил цену
  (`set_addon_price` = осознанное решение). Предварительные цены на 28.09.2026: Business Address $179/год,
  Form 5472 $349/год, DE Expedited $375 — **все три выключены**, себестоимость не подтверждена
  (письмо поставщику адреса, ответ CPA по 5472, точная модель DE expedited — тариф штата вырос с 1 авг. 2026).
- **DE Expedited** блокируется после факта подачи в штат (`order_milestones.state_filed`) — ускорять уже поздно.
- **Годовые услуги** — `period_number` (1 = первый год, 2 = продление). Автоматические продления и напоминания — отдельная работа.
- Партнёр не видит ни add-ons, ни их цен и оплат.
- Отмена: клиент/админ — только неоплаченный запрос. Оплаченная услуга отменяется админом отдельным решением (возврат — по политике).
