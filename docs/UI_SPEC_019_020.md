# Интерфейс под миграции 019–020

## Оплата (Partners, админ)
1. Перед кнопкой «Отметить оплату» вызвать `order_payment_due(p_order)` и показать: **«К получению: $X (пакет $A + услуги $B)»**.
2. Кнопка вызывает `mark_order_paid_manually(p_order, p_note, p_amount_cents = total_cents)` — **всегда форму с суммой**.
   Поле «Получено, $» с предзаполненной должной суммой; если админ изменил — сервер ответит «Amount mismatch».
3. Ошибки: `Amount mismatch` → «Сумма не совпадает с должной (нужно $X)» (X из `details: expected_cents=…`);
   `Amount required` → «Введите полученную сумму»; `Price not configured` → «Для продукта не задана цена».
4. Админ-экран цен: список `product_prices`, кнопка изменения → `set_product_price(p_product, p_price_cents)`.

## Клиентский чекаут
- Сводка справа = `order_payment_due(p_order)`: пакет + выбранные услуги = итого (та же сумма, что ждёт админ).

## Возвраты (админ)
- Форма показывает «Оплачено $P, уже возвращено $R, доступно $P−R». Ошибки: `Order not paid` → «Заказ не оплачен»;
  `Refund exceeds amount paid` → «Больше оплаченного (оплачено … возвращено …)»; `Duplicate refund` → «Такой возврат только что записан»;
  `Scope does not match order` → «Эта часть не относится к заказу».

## Партнёр
- Отменённые заказы исчезают из списка сразу; завершённые — через 30 дней. Причину отмены не показывать.
- Сообщение `Operation id reused` → «Действие уже обработано, обновите страницу».

## Анкета клиента
- `Field too long` → «Слишком длинное значение (имя ≤ 200, страна ≤ 100, компания ≤ 200, деятельность ≤ 1000)»;
  `Invalid characters` → «Уберите символы < и >»; `Invalid contact value` / `Invalid preferred time` → соответствующие подсказки.
- `Order setup incomplete` (партнёр/админ при включённой проверке) → «Анкета не заполнена: владельцы, доли 100%, ответственный, данные компании, паспорта».

## Админ
- `Cannot mark a cancelled order as paid` (сбой вебхука) → «Заказ отменён: платёж нужно вернуть вручную».
- Настройка «Проверять полноту анкеты» (кнопка → `set_order_setup_enforcement`) — включать после перехода на мастер `/app/start`.
